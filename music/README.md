## ✅ Checklist

- [ ] Descargar las canciones de forma legal (iTunes, Amazon Music, etc.)
- [ ] Renombrar los archivos según la lista anterior
- [ ] Copiar todos los archivos a esta carpeta `music/`
- [ ] Verificar que todos los archivos sean formato MP3
- [ ] Abrir la aplicación y disfrutar la música 🎵

## 📝 Notas Importantes

- Los nombres de archivo DEBEN ser exactamente como están listados (sin mayúsculas, con guiones)
- Todos deben ser formato MP3
- Tamaño recomendado: 3-5 MB por canción (calidad normal)
- Si falta alguna canción, el reproductor la omitirá automáticamente

## 🎼 Playlist Final

Una vez agregadas todas las canciones, tendrás una hermosa playlist romántica de 12 canciones perfectas para escuchar mientras cultivas flores en el jardín. 💕🌸
